# Project 2 - GaitPart Reproduction and Investigation

## Course

COSC 594 - Biometrics  
Project 2: Reproduce + Investigate

## Overall Topic

Vision-based gait recognition.

This project continues the gait identification problem developed in
Project 1.

## Project 1 Baseline

Project 1 used a Gait Energy Image (GEI) representation with
Euclidean nearest-neighbor matching on CASIA-B.

Final Project 1 result:

- Rank-1 accuracy: 95.93%
- Controlled 090-degree normal walking condition

Project 2 moves from this simple baseline toward reproduction and
competitive analysis of a modern gait recognition method.

## Primary Reproduction Paper

Fan et al.,
"GaitPart: Temporal Part-Based Model for Gait Recognition,"
CVPR 2020.

## Project 2 Objective

Reproduce GaitPart as faithfully as practical and investigate factors
that affect its biometric identification performance.

The reproduction protocol, deviations from the paper, experiments,
results, and software environment will be documented throughout the
repository.

## Current Investigation Direction

Potential investigations include:

- normal walking vs. bag-carrying vs. clothing-change conditions
- viewpoint robustness
- sequence-length sensitivity
- comparison with the Project 1 GEI baseline

The final investigation will be selected after the GaitPart reproduction
protocol is fully reviewed.
